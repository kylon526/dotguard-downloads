A focused URL filter with a desktop app and an independent menu bar monitor.

Download DMG for Mac Apple Silicon · macOS 15 or later · Existing DotGuard setup required

Opening DotGuard for the first time

  1. Open the DMG and drag DotGuard.app to Applications.
  2. Try opening it. If macOS says Apple could not verify the app, click Done.
  3. Go to System Settings → Privacy & Security → Security and click Open Anyway for DotGuard. Confirm Open and authenticate if asked.

This approves DotGuard specifically. The DMG does not remove the warning: this build is not Apple-notarized. Apple’s instructions.

Before you install

The DMG opens a custom drag-to-Applications window with just two icons. The app contains its monitor, CLI, gateway, and Python runtime, so there are no loose support files to copy. It does not include your rules, protector key, certificates, or network settings.

All software is bundled inside DotGuard.app. Dragging it copies the app, monitor, CLI, gateway, and runtime together; it does not configure services or re-register an existing monitor job. The app is locally signed and is not Apple-notarized. Coordinated installation, automatic updates, and automatic repair are not included yet. The DMG shows just DotGuard and Applications; drag the app icon to copy all bundled software.
